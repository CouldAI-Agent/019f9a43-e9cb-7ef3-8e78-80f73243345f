# Fool of Star

Fool of Star is a high-performance, ultra-secure, end-to-end encrypted global multi-currency payment application, personal wallet, and private trading ecosystem. It features an integrated, privacy-first personal AI assistant and a native private app coin for global trade. The underlying architecture is robust, enterprise-grade, and zero-knowledge, but wrapped in a beautiful, frictionless, and incredibly simple user interface that anyone can navigate with ease.

## Features

- **Biometric & Passwordless Access**: Secure, instant logins using modern on-device capabilities.
- **Unified Balance View**: Displays all asset holdings converted into your preferred local currency in real-time.
- **Personal AI Assistant**: A native assistant that processes queries on-device and allows for natural language operations (e.g., "Send $15 to Sarah for lunch").
- **Multi-Currency & Swap UI**: Support for traditional cash, major stablecoins, and the native private utility coin. Seamlessly swap between currencies.
- **DigiLocker Secure Vault**: End-to-end encrypted secure vault for storing official documents digitally.
- **Zero-Knowledge Brokerage**: A flat 1% encrypted brokerage managed automatically in the background by the AI Agent.

## Tech Stack

- **Framework**: Flutter
- **Language**: Dart
- **Design System**: Material 3 (Dark Theme)
- **Architecture**: Single-file prototype UI for fast iteration and visualization

## Running the App

To run this application locally:

1. Ensure you have the [Flutter SDK](https://flutter.dev/docs/get-started/install) installed.
2. Clone this repository.
3. Run `flutter pub get` to install dependencies.
4. Run `flutter run` to launch the app on your connected device or emulator.
